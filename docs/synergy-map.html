Hero Synergy Map

Every hero skill, item, banner, battlefield, omen and champion affix, tagged by the theme keywords it makes, uses or hurts. Synergies are counted from those tags: a link is one hero making a keyword that another (or the same) hero uses. Rule texts come straight from the game data (tools/dev.sh synergy refreshes them); numbers are placeholders.
