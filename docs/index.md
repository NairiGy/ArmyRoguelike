# ArmyRoguelike: design docs

A turn-based roguelike army-builder in Unity, in development. Code and README: [github.com/NairiGy/ArmyRoguelike](https://github.com/NairiGy/ArmyRoguelike).

- [Game design document](gdd.html): the game on a few pages: vision, pillars, loop, battle, army, enemies, art and roadmap.
- [Gamepedia](gamepedia.html): every unit, ability, item, enemy and rule with its numbers, generated from the game data.
- [Hero synergy map](synergy-map.html): every hero skill, item and rule tagged by theme, with its role in a build and a judgment.
- [Enemy faction map](faction-map.html): each faction's plan, unit roles, combos and the hero themes that answer it.
- [Design note](design-note.md): what has been decided and why.
- [Design history](design-history.md): replaced rules and why they were replaced.
